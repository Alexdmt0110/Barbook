\# Barbook



Barbook est une application web de gestion de recettes de cocktails.



\## Objectif V1



La première version doit permettre à un utilisateur de :



\- créer un compte ;

\- gérer ses recettes de cocktails ;

\- consulter une fiche détaillée ;

\- rechercher et filtrer ses recettes ;

\- organiser ses cocktails avec des tags et des dossiers.



Les fonctionnalités collaboratives, la gestion de stock et les fournisseurs sont prévues pour des versions ultérieures.



\## Stack



\- Frontend : Angular

\- Backend : NestJS

\- Base de données : PostgreSQL

\- ORM : Prisma

\- Développement local : Docker Compose

\- Production cible : VPS + Nginx + Docker
